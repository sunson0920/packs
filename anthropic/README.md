# Anthropic ($ANT)

Static one-page meme-coin site generated by Meme Site Studio (template: c52-bureau-nebula).

- No build step: Vercel serves index.html directly (vercel.json).
- One click: **🚀 Deploy** in Meme Site Studio commits this folder to GitHub and deploys it on Vercel (project `anthropic`, Root Directory `anthropic`).
- By hand: push this folder to GitHub, import the repo in Vercel (Root Directory = this folder if the repo holds several sites), then add the domain **anthropicant.si** under Project → Settings → Domains.
- site.json holds every input; import it (or this whole zip) back into Meme Site Studio to update the site. Re-exporting overwrites the hand-edited `index.html`.

## Layout

`index.html` is a warm cream meme page. The star is `assets/art/mascot-reference.png`: a fuzzy brown ant with large black eyes, two antennae, and a cream cap. That file is the community character, not an official mascot. Two further drawings, `assets/art/mascot-meme-2.webp` and `assets/art/mascot-meme-3.webp`, sit in the sketches section. Fonts are local Outfit files under `assets/fonts/`. Motion stops under `prefers-reduced-motion`.

There is no package manager, no lockfile, and no build. This folder is the static production export. From the folder:

```
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`. Opening `index.html` directly also renders the page. Copy-to-clipboard is most reliable over http or https.

Images that showed a Nasdaq mark, an SEC filing, a valuation, or an IPO scene are not part of this page. `assets/banner.webp` and the matching city banner were removed because they printed unverified market figures.

The contract is `0x0b84cd2a58159057fe71a1a9438a72c5c97ab985`. On-chain reads and the Sourcify exact-match source name it Anthropic, symbol ANT, 18 decimals, total supply 1,000,000,000. Dexscreener’s pair for that contract is Uniswap v4 ANT/ETH, id `0x08f1de596f5917010b753dd7549ee1bdef3c59c0dd05baebad42cc43a87b91aa`, and the page embeds that pair. ## Custom domain: anthropicant.si

Status: Live

1. Push this folder to GitHub and create a Vercel project from it.
2. In Vercel → Settings → Domains, add `anthropicant.si` (and `www.anthropicant.si`).
3. At your registrar, in the DNS settings of `anthropicant.si`, add:

| Type | Name | Value |
|------|------|-------|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

   If Vercel shows a different (project-specific) IP or CNAME target in Settings → Domains, use Vercel’s values. Remove other A/AAAA records on the same name.
4. Wait for DNS to update (minutes, up to 48 h). Vercel issues HTTPS automatically.

Check: `dig +short A anthropicant.si` should return 76.76.21.21.
