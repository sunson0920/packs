# Anthropic ($ANT)

Static one-page meme-coin site generated by Meme Site Studio (template: c52-bureau-nebula).

- No build step: Vercel serves index.html directly (vercel.json).
- One click: **🚀 Deploy** in Meme Site Studio commits this folder to GitHub and deploys it on Vercel (project `anthropic`, Root Directory `anthropic`).
- By hand: push this folder to GitHub, import the repo in Vercel (Root Directory = this folder if the repo holds several sites), then add the domain **antoneth.fun** under Project → Settings → Domains. The older host anthropicant.si is not removed by this folder.
- site.json holds every input; import it (or this whole zip) back into Meme Site Studio to update the site. Re-exporting overwrites the hand-edited `index.html`.

## Layout

`index.html` follows the public colony layout: floating nav, grass line, orbit coin, depth meter, ticker, lore chamber, archive, four buy steps, tokenomics, dig plan, FAQ, and swarm. The logo in the nav, coin, and footer is the supplied cream-cap ant, `assets/logo.png`. Display type is local Bricolage Grotesque. The contract, copy buttons, and Uniswap links use `0xd8aa2557e62c508a8e167b711bab4172b74bc5d6`. The chart is the Uniswap v4 ANT/ETH pair. X is `https://x.com/anthropiceth_x`. Telegram is `https://t.me/anthropiceth_tg`. Reduced motion stops the swarm, the tunnel walkers, and the ticker.

There is no package manager, no lockfile, and no build. This folder is the static production export. From the folder:

```
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`. Opening `index.html` directly also renders the page. Copy-to-clipboard is most reliable over http or https.

Images that showed a Nasdaq mark, an SEC filing, a valuation, or an IPO scene are not part of this page. `assets/banner.webp` and the matching city banner were removed because they printed unverified market figures.

## Custom domain: antoneth.fun

Intended address: https://antoneth.fun/

Public DNS checked on 18 Nov 2026 returned NXDOMAIN for `antoneth.fun`. The connected Vercel domain config listed no A record and no CNAME, with `misconfigured: true`. `anthropicant.si` is the host already attached to this project and was not removed.

When the name is delegated, the records Vercel recommends are:

1. Push this folder to GitHub and create a Vercel project from it.
2. In Vercel → Settings → Domains, add `antoneth.fun` (and `www.antoneth.fun`).
3. At your registrar, in the DNS settings of `antoneth.fun`, add:

| Type | Name | Value |
|------|------|-------|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

   If Vercel shows a different (project-specific) IP or CNAME target in Settings → Domains, use Vercel’s values. Remove other A/AAAA records on the same name.
4. Wait for DNS to update (minutes, up to 48 h). Vercel issues HTTPS automatically.

Check: `dig +short A antoneth.fun` should return 76.76.21.21 once those records exist. Until then the name does not resolve.
