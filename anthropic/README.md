# Anthropic ($ANT)

Static one-page meme-coin site generated by Meme Site Studio (template: c52-bureau-nebula).

- No build step: Vercel serves index.html directly (vercel.json).
- One click: **🚀 Deploy** in Meme Site Studio commits this folder to GitHub and deploys it on Vercel (project `anthropic`, Root Directory `anthropic`).
- By hand: push this folder to GitHub, import the repo in Vercel (Root Directory = this folder if the repo holds several sites), then add the domain **anthropicant.si** under Project → Settings → Domains.
- site.json holds every input; import it (or this whole zip) back into Meme Site Studio to update the site. Re-exporting overwrites the hand-edited `index.html`.

## Layout

`index.html` is an editorial page with a dark field hero, a letter-split `$ANT`, a lightweight network canvas, and ivory sections below. Node labels, a step track, and a scrolling tape follow the hierarchy of a community reference page. The contract stays `TBA`. Motion turns off under `prefers-reduced-motion` and the canvas is hidden below 901px.

Kept from `site.json`: name Anthropic, ticker ANT, chain Ethereum, contract `TBA`, Uniswap `https://app.uniswap.org/`, Dexscreener `https://dexscreener.com/ethereum`, X `https://x.com/anthropiconeth`. Supply, tax, and liquidity are blank there, so the page does not print template stand-ins. The banner is shown as artwork, not as a listing or filing. This is an independent community page, not Anthropic the AI company.

## Custom domain: anthropicant.si

Status: Live

1. Push this folder to GitHub and create a Vercel project from it.
2. In Vercel → Settings → Domains, add `anthropicant.si` (and `www.anthropicant.si`).
3. At your registrar, in the DNS settings of `anthropicant.si`, add:

| Type | Name | Value |
|------|------|-------|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

   If Vercel shows a different (project-specific) IP or CNAME target in Settings → Domains, use Vercel’s values. Remove other A/AAAA records on the same name.
4. Wait for DNS to update (minutes, up to 48 h). Vercel issues HTTPS automatically.

Check: `dig +short A anthropicant.si` should return 76.76.21.21.
